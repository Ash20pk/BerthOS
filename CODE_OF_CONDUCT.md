# Code of Conduct

Berth is a small, early, solo-maintained project. The bar is simple:

- Be respectful in issues, PRs, and discussions. Disagree about code and ideas, not about people.
- No harassment, personal attacks, or discriminatory language or behavior, in this repo or in any space connected to it.
- Assume good faith, especially with first-time contributors — everyone's first PR against an unfamiliar codebase is rough.

Maintainers may edit, remove, or lock content that violates this, and may block repeat offenders from the repo.

To report a concern, open a private message to [@Ash20pk](https://github.com/Ash20pk) rather than a public issue.

This is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), kept short deliberately for where this project is today.
